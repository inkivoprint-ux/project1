# Application audit — 30 September 2026

> Historical checkpoint: this report predates Git initialization, the shared catalogue/template implementation, order hardening and live Supabase setup. See [current deployment status](deployment-2026-09-30.md). Statements below about missing Git/shared storage/live setup describe the earlier audit, not current status.

## Baseline preserved

The folder already contained the storefront, four products, admin dashboard/template editor, cart/WhatsApp order handoff, local order blobs, Supabase schema/API foundation, Malayalam font files, text opacity/style/surface controls and existing tests. These were inspected and extended, not recreated. The supplied handoff block contained a placeholder rather than a complete summary, so the files were the source of truth. Git is not initialized; it was not initialized by this session.

## Changes and fixed issues

- Removed visible reviews, ratings, profile/wishlist icons, dead newsletter/footer/navigation links and unsupported numeric trust claims. Legacy product rating fields are stripped on load/save without deleting business data.
- Refined branded layout, typography, forms, spacing, responsive cards, admin navigation, template controls and cart scrolling. Added contact links and bottom-right responsive Webappzz credit opening separately.
- Added keyboard focus handling, Escape dismissal, body-scroll locking, closed-dialog inertness, skip link, readable labels, labelled position buttons and reduced-motion support.
- Fixed carts merging different designs, invalid quantities, stale saved-design state after editing, and corrupt saved order/catalogue records.
- Added product editing and ensured local product overrides are read by both customer and template routes.
- Separated draft/published templates, protected the working published version on reset/save failures and kept version increments monotonic. Removed redundant unbounded template-history writes; old stored history is left untouched.
- Baked masks/perspective/opacity into exported canvas pixels; applied blend when composing exports and corrected rotated preview placement. File generation waits for actual renderer readiness and reports failure.
- Hardened payload/phone/filename/duplicate-file validation and server-side price checks. Customer submissions no longer overwrite database catalogue prices. Orders capture actual physical/template settings instead of invented flat defaults.
- Added authenticated cloud-order listing and private-file retrieval, admin sign-in/sign-out, role lookup migration and cloud/local file error messages. Empty order lists can refresh.
- Updated page metadata, canonical URLs, responsive image loading and documentation. Admin/API paths stay excluded from indexing.

1. Supply real Supabase environment configuration and apply both migrations in order. Verify admin/customer role permissions, server-side price checks, uploads, database records, cross-device listing, private previews/downloads and deletion against the real project.
